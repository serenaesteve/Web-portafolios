                            🌐 ARQUITECTURA DEL SISTEMA
================================================================================

REQUEST FLOW:

1. Usuario accede a "juan.portify.es"
   ↓
2. DNS resuelve a IP del servidor
   ↓
3. Nginx/Apache proxea a Flask (127.0.0.1:5000)
   ↓
4. Flask middleware detecta subdominio "juan"
   ↓
5. Ruta "/" busca portfolio por usuario_slug="juan"
   ↓
6. Si existe: retorna HTML del portfolio
   Si no existe: retorna error page

PARA PONER EN PRODUCCIÓN:

1. [DNS] Configurar wildcard record
   - *.portify.es IN A 192.168.x.x
   - Esperar 24-48 horas propagación

2. [WEB SERVER] Configurar Nginx o Apache
   - Usar configuración de SUBDOMAIN_SETUP.md
   - Probar: nginx -t / apache2ctl configtest

3. [ENTORNO] Establecer variables
   - export DOMAIN_BASE=portify.es
   - export SECRET_KEY=<tu-clave-segura>

4. [APLICACIÓN] Iniciar Portify
   - python3 app.py
   - O con Gunicorn: gunicorn -w 4 -b 127.0.0.1:5000 app:app

5. [HTTPS] Configurar SSL
   - certbot certonly --nginx -d portify.es -d '*.portify.es'
   - IMPORTANTE: No saltear esto en producción

6. [TESTING] Verificar funcionamiento
   - Crear un portfolio
   - Acceder desde usuario.portify.es
